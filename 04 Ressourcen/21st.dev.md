# 21st.dev

Spezialisierte UI-Komponentenbibliothek und Suchmaschine für KI-gestützte Entwicklung.

## Was ist das?

Repository für moderne, animierte UI-Komponenten auf Basis von **Tailwind** und **Shadcn/ui** — optimiert für den Einsatz mit KI-Tools wie Cursor, Lovable, Bolt oder v0. Komponenten können direkt per Prompt in Projekte integriert werden.

## Link

[21st.dev](https://21st.dev/home)

## Einsatz

- Schnelle UI-Prototypen mit KI-Unterstützung
- Referenz für animierte Komponenten-Patterns
- Inspiration für eigene Komponenten-Bibliotheken

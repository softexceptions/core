# OOP-Konzept-Zerlegung in Rust (Diagramm)

Visualisiert das Kernargument aus [[OOP-in-Rust]]: „OOP" bündelt **vier trennbare Konzepte** — Rust erfüllt Kapselung, Abstraktion und Polymorphie (über `struct`/`impl`, `trait`, Generics/`dyn`), verzichtet aber auf **Vererbung** und ersetzt sie durch Komposition + Default-Methoden + Trait-Objekte.

**Visuelle Hauptaussage:** OOP-*Ziele* sind von OOP-*Mechanismen* (Vererbung) trennbar.

## 📚 Gelernt heute

- UniFi Network 10: Port-Forwarding ist unter **Internet → (WAN auswählen)** versteckt, nicht im Hauptmenü
- NPM läuft auf Port 9081 (nicht Standard 80) — Forward Port im NPM muss entsprechend angepasst werden
- `git: command not found` auf frischem Debian LXC → erst `apt-get update && apt-get install -y git`
- `DRY_RUN` serverseitig und App-Toggle sind unabhängig — für echten Betrieb müssen beide auf Live/false stehen
- Kia API `engine_is_running` liefert gecachte Daten — nicht zuverlässig genug für harten Send-Block
- GoingElectric → OCM Fallback: bei API-Fehler `None` zurückgeben damit Fallback greift
